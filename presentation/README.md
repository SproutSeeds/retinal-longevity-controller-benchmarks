# Presentation

`retinal-public-data.pdf` is the shareable 11-slide deck. `retinal-public-data.pptx` contains editable text, three native charts with embedded workbooks, and a native study-design table. `spoken-notes.txt` and the matching Markdown render contain the narration. Source links are in the PowerPoint speaker notes and `slide-sources.json`.

Research status: October 17, 2026. Computational checks pass within their stated scope; biological experiment replacement remains inconclusive. The funding design is conditional and contains quantities rather than unquoted dollar estimates.

The deck is generated by `build.mjs` with `@oai/artifact-tool` 2.8.59, using the corresponding presentation validation helpers. Set absolute `SKILL_DIR`, `DECK_WORKSPACE`, `DATA_DIR`, `RUNTIME_NODE_MODULES`, `RUNTIME_BIN_DIR` and `RUNTIME_PYTHON` for the installed runtime. Link that runtime's `node_modules` into a private build directory. `DATA_DIR` points to `research/2026-10-public-data`. Run the script with the runtime Node executable; use a fresh output directory for each revision. The source intentionally requires those tools rather than silently installing replacements.

The authored font is Liberation Sans. PDF conversion used LibreOffice with an explicit font configuration pointing to the installed font files; all fonts are embedded. Every rendered PDF page was visually inspected. See `QA.json` for file hashes and the scope of structural and visual verification. Interactive editing in desktop PowerPoint was not exercised.

The public research folder contains the analysis contract, complete numerical values, source credit, model card and conditional measurement proposal. Displayed chart values are rounded to three decimal places in the embedded workbooks and formatted for readability; the scientific JSON retains full precision.
