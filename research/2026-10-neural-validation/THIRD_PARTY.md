# Source attribution and redistribution

Our authored analysis code and documentation use the repository's [MIT license](../../LICENSE). Original experiments, source data, third-party software and source publications retain their own terms.

- Xu et al., [Nature Aging 2024](https://doi.org/10.1038/s43587-024-00594-3): mouse neural tissue and cultured neural experiments; [GSE224438](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE224438), [GSE245385](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE245385), [Zenodo 10626910](https://doi.org/10.5281/zenodo.10626910). The Zenodo records identify CC BY 4.0. The packet contains attributed derived summaries and small metadata excerpts; raw RDS, matrices, publisher workbook and full article are fetched separately or remain in the local cache.
- Lu et al., [Cell 2025](https://doi.org/10.1016/j.cell.2025.07.031): [GSE297233](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE297233) and [GSE297234](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE297234). GEO availability is not an assignment of our software license to the original data. The public packet contains aggregate results; original count/H5 files remain at their source. The internal human barcode-level audit table is excluded.
- [HGNC HCOP](https://www.genenames.org/tools/hcop/), including the HGNC-supported mouse mappings and source identifiers, is credited in the orthology manifest. The downloaded mapping snapshot is hash-pinned. The human HGNC feature mapping is separately pinned; a later live snapshot must not silently replace it.
- Public repository metadata from Zenodo, NCBI, ENA, Europe PMC and Cambridge are retained as source snapshots or concise factual extracts with original URLs and checksums. The Cambridge thesis is access-limited; its full text and matrix are not redistributed.

The source author scripts were inspected as text and are linked at their original commit. They were not executed or relicensed. Numerical replay uses separately authored Python code with pinned rdata, NumPy, pandas, SciPy and h5py environments. Plotting uses Matplotlib. The presentation contains native editable charts and tables; its builder requires the installed Artifact Tool presentation runtime. The statistical code and public checks do not depend on that presentation runtime.

The public export excludes private correspondence, account details, local attention records, raw model transcripts, raw biological matrices and the internal human barcode table. Historical frozen commits identify the original analysis chronology; the public export also supports explicit archived-hash verification without that private Git history.
