**October 18, 2026. Historical tAge replication remains pending because the required inputs are unconfirmed.** No tAge or TACO model has been executed in this project. There is no independently calculated competing estimate of the reported GSTA4 age reduction.

This packet prepares the input checks and comparison workflow for that calculation. It keeps a known reference example, a historical study replay and biological interpretation as separate stages. Synthetic examples exercise the software; they contain no observed biological outcomes.

## What is complete and what is pending

| Item | Current state | What it establishes |
|---|---|---|

| Historical GSTA4 tAge calculation | Pending; no clock executed | Requires the exact historical model, processing references and an identified input/output example. |

| Biological interpretation | Unresolved | A numerical match alone cannot establish durability, safety or functional benefit. |

The OSK expression correlation uses a different intervention contrast and endpoint from the GSTA4 clock calculation. It does not test the reported 8.5-month result. The original experiments and predictions belong to [Lu and colleagues](https://doi.org/10.1101/2025.08.30.673239). Their paper already distinguishes OSK from GSTA4 and examines loss of oxidative protection after OSK withdrawal in cultured ARPE-19 cells.

## The next executable sequence

1. Identify the historical model and preprocessing, including missing-gene reference values and the old-control centering reference. Resolve permissible use of each supplied artifact.
2. Validate files, gene/sample identifiers and a small processed reference input with expected predictions. Preserve a hash-bound comparison plan before inspecting new outputs. The published aggregate is already known; this is a retrospective reproduction exercise.
3. Review and implement the historical model adapter as a separate, explicitly verified change. This preparation release does not execute supplied scripts or serialized models.
4. Run the reference example and assess numerical agreement under the recorded tolerances. Record disagreements without tuning the comparison after seeing them.
5. Only after the reference step succeeds, admit the original study inputs and compute sample-level results. Establish animal, eye and cohort joins before population or functional interpretation.
