# Source attribution and reuse

Independently written analysis code and authored documentation in this repository use its MIT license. That license does not relicense third-party articles, software, model weights or data.

- Plesa et al., *Nature Aging* (2026), DOI [10.1038/s43587-026-01234-8](https://doi.org/10.1038/s43587-026-01234-8): publisher source-data tables supply the reference values. Extracted numerical references retain workbook/sheet/row provenance. The full publisher workbooks and article are fetched from their original URLs and are not redistributed here. The clock code was inspected for dependencies; no model was executed.
- Berdugo-Vega et al., *Neuron* (2026), DOI [10.1016/j.neuron.2025.11.028](https://doi.org/10.1016/j.neuron.2025.11.028), GEO [GSE276656](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE276656): the paper identifies a CC BY 4.0 license. Numerical derivatives are attributed to the public GEO source. No accession-specific data license was identified in the retrieved record; original matrices remain at the source and outside this release. The inspected author code repository had no LICENSE at its pinned commit; it was not copied or executed.
- Xu et al., *Nature Aging* (2024), DOI [10.1038/s43587-024-00594-3](https://doi.org/10.1038/s43587-024-00594-3), and Lucy Xu's [2022 Stanford dissertation](https://purl.stanford.edu/ck834ff5386): source facts and repository metadata establish design and assignment requirements. The full dissertation and publisher PDFs are not redistributed. The paper, thesis and repository reflect related experiments, not independent replication of each other.
- GEO [GSE350289](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE350289): fresh metadata checks are attributed to the deposited series. The original workbook is not redistributed.
- Prior public project packets retain their existing source terms and original attribution. Current search inventories include links and minimal public metadata; availability is not permission to execute arbitrary third-party code or reuse an unpublished file.

Any newly supplied author data need an explicit scope of permitted use and public release. No private correspondence, credentials, raw human barcode table or raw count matrix is included in the reviewed publication allowlist. Pseudobulk counts in this packet are derived animal-level aggregates from the public mouse study.
