# Source credit and reuse

Original experimental work remains attributed to the linked research teams and deposits. This repository's MIT license covers our code and authored documentation; it does not relicense third-party data, papers, software or model weights.

Raw expression matrices, downloaded papers and author code are fetched from their original providers and are excluded from Git. The source manifest records URLs, retrieval status, sizes and hashes. Consult each provider's record and terms before redistributing or applying its material. Derived results include source identifiers so analyses remain attributable.

The current tAge resources use the MGB Open Access Software License with purpose/use conditions. We have not executed or redistributed those weights or copied that source into this package. Exact historical-model identity and appropriate use rights remain prerequisites for a future replay. See the [author license](https://github.com/Gladyshev-Lab/tAge/blob/main/LICENSE).

The older repository citation and Zenodo DOI cover an earlier benchmark release. Cite this research checkpoint using its public Git commit and date, and cite the original studies for their experiments. A new DOI has not been minted for this analysis revision.
